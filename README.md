# futzed-wheels

This repository contains scripts for generating "futzed" Python wheels,
which are wheels that are slightly off from what normal Python tooling expects.

Some of the futzes are non-standard, while others are thing that are
technically valid (due to underspecification in the wheel spec) but that are not
commonly used or supported in practice.

## Usage

The latest release for this repository has artifacts for each of the futzed
wheels.
